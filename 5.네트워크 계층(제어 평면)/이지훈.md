# 네트워크 5장 복습 질문 3개

## 질문 1. OSPF와 BGP는 각각 어디에서 사용되고, 길을 고르는 기준은 어떻게 다른가?

### 답변

**OSPF는 한 회사나 통신사의 내부 네트워크에서 사용한다.** OSPF는 라우터 사이의 링크 비용을 더해서 비용이 가장 작은 길을 선택한다.

**BGP는 서로 다른 회사나 통신사의 네트워크 사이에서 사용한다.** BGP는 단순히 가장 짧은 길만 고르지 않는다. BGP는 회사 사이의 계약이나 보안 같은 정책도 함께 고려한다.

쉽게 말하면 **OSPF는 한 동네 안에서 가까운 길을 찾고, BGP는 여러 동네 사이에서 규칙에 맞는 길을 찾는다.**

---

## 질문 2. 네트워크의 링크가 끊어지면 OSPF와 SDN은 새로운 길을 어떻게 찾는가?

### 답변

**OSPF를 사용하는 라우터들은 링크가 끊어졌다는 정보를 서로 공유한다.** 각 라우터는 바뀐 네트워크 지도를 보고 새로운 길을 다시 계산한다.

**SDN에서는 스위치가 링크 장애를 SDN 컨트롤러에 알린다.** SDN 컨트롤러 쪽의 프로그램이 새로운 길을 계산하고, SDN 컨트롤러가 필요한 스위치의 규칙을 바꾼다.

쉽게 말하면 **OSPF에서는 라우터들이 각자 새 길을 계산하고, SDN에서는 중앙 지휘부처럼 동작하는 소프트웨어가 새 길을 계산한다.**

---

## 질문 3. ping, traceroute, SNMP는 각각 어떤 상황에서 사용하는가?

### 답변

**ping은 상대 컴퓨터가 응답하는지와 응답이 돌아오는 데 걸린 시간을 확인할 때 사용한다.** ping 응답이 없더라도 상대 컴퓨터가 반드시 꺼졌다고 단정할 수는 없다.

**traceroute는 목적지까지 가는 동안 어떤 라우터들이 응답하는지 살펴볼 때 사용한다.** traceroute를 사용하면 문제가 발생한 것으로 의심되는 구간을 좁힐 수 있다.

**SNMP는 라우터나 스위치의 상태와 통계를 확인할 때 사용한다.** 관리자는 SNMP로 장비의 오류 횟수나 버린 패킷 수를 확인할 수 있다.

쉽게 말하면 **ping은 목적지의 응답을 확인하고, traceroute는 이동 경로를 살펴보며, SNMP는 네트워크 장비의 상태를 확인한다.**

---

## 답변에 나온 핵심 용어 설명

- **OSPF**: 하나의 자율 시스템 내부에서 비용이 가장 작은 경로를 계산하는 라우팅 프로토콜이다.
- **BGP**: 서로 다른 자율 시스템 사이에서 경로 정보를 교환하고 정책에 맞는 경로를 선택하는 라우팅 프로토콜이다.
- **링크**: 라우터나 스위치 같은 네트워크 장비를 연결하는 통신 경로다.
- **링크 비용**: 링크를 이용할 때 드는 부담을 숫자로 표현한 값이다. 값이 작을수록 더 좋은 길로 취급한다.
- **정책**: 어떤 네트워크의 트래픽을 받아들이거나 전달할지 정하는 사업·보안·운영 규칙이다.
- **SDN**: 패킷을 전달하는 장비와 경로 규칙을 만드는 소프트웨어를 논리적으로 분리한 네트워크 구조다.
- **SDN 컨트롤러**: 네트워크 상태를 관리하고 스위치에 새로운 전달 규칙을 보내는 소프트웨어 시스템이다.
- **ping**: ICMP 요청과 응답을 이용해 목적지의 응답 여부와 왕복 시간을 확인하는 도구다.
- **traceroute**: 목적지까지 가는 과정에서 응답한 라우터와 왕복 시간을 관찰하는 도구다.
- **SNMP**: 관리자가 네트워크 장비의 상태와 통계를 확인할 때 사용하는 관리 프로토콜이다.
- **패킷**: 인터넷에서 전송하기 좋게 작게 나눈 데이터 묶음이다.
